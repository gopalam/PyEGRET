# R source reference

Unmodified copies of the R sources that PyEGRET translates, kept here so a
function can be translated line by line against its original.

| folder | package | version | upstream commit |
|---|---|---|---|
| `EGRET_R/` | EGRET | 3.0.12 | b5eb22c (2026-07-13) |
| `EGRETci_R/` | EGRETci | 2.0.5 | 929da9f (2025-04-04) |

Sources: https://github.com/DOI-USGS/EGRET and https://github.com/DOI-USGS/EGRETci.
Both are USGS software released under CC0 (public domain).

These files are reference only; nothing in `pyegret/` imports or runs them.
